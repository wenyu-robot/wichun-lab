# Contributing to Wichun.lab

Wichun.lab is an early-stage learning and research project. Corrections, references and reproducibility suggestions are welcome.

- Use Issues for suggestions, typos, incorrect equations or broken references.
- Include reliable original sources when proposing corrections.
- Distinguish hypotheses and ideas from verified findings.
- Do not submit confidential code or data, private project artifacts, or third-party PDFs/images without permission.
- Discuss major additions in an Issue first.

A formal content/software license has not yet been selected. Please discuss substantial original contributions before submitting them.
